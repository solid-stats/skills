# skills

**Русский** · [English](README.en.md)

Общий набор навыков (skills) для AI-агентов платформы **Solid Stats** —
статистики игр сообщества [Solid Games](https://sg.zone) (ArmA 3). Установите
навык в любой репозиторий Solid Stats, и агент сам применит его при ревью кода,
планировании и разработке.

Навыки не привязаны к конкретному агенту и следуют формату
[skills.sh](https://www.skills.sh/). Они задают единые инженерные стандарты для
TypeScript-бэкенда (`server-2`), ингест-CLI (`replays-fetcher`),
Rust-парсера OCAP (`replay-parser-2`) и фронтенда на React / TanStack Start
(`web`).

Это вспомогательный репозиторий платформы: рантайм-границ не несёт — задаёт
правила, по которым пишут код остальные репозитории.

> Solid Stats от и до строят AI-агенты по процессу
> [GSD](https://github.com/open-gsd/gsd-core). Разработка вне GSD — вне процесса.

## Быстрый старт

Выбрать навык из всех доступных в репозитории:

```bash
npx skills add solid-stats/skills
```

Установить конкретный навык:

```bash
npx skills add solid-stats/skills/<skill-name>
```

Обновить установленные навыки до последней версии:

```bash
npx skills update            # спросит область: Project / Global / Both
bash ./scripts/update-all-skills.sh   # обновить всё везде (глобальные + все проекты)
```
